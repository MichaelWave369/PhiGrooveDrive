# ΦGrooveDrive

An experimental, browser-first laboratory for Liquid-dance-inspired relational actuator control.

**Status:** PROPOSED / SIMULATED. No physical propulsion or energy recovery has been demonstrated.

Research theory: [NestedBubbleGear / LIQUID-BGA-01](https://github.com/MichaelWave369/NestedBubbleGear/blob/main/docs/LIQUID_INTERFACE_BUBBLE_GEAR_ALTERMATH_V0_1.md).

This repository is under initial development. Experiment LIQ-E0 investigates the behavior of two coupled masses with a changeable rest-gap actuator, preserving momentum and accounting for energy.
